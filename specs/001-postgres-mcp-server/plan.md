## Summary

Build an MCP server that enables AI agents to query SQL databases using natural language or SQL. The server provides three tools (`query`, `schema`, `help`) with read-only access, AI-powered natural language translation via Anthropic/Bedrock/OpenAI, and support for multiple database connections configured via environment variables. Initial implementation supports PostgreSQL, with architecture designed for future MySQL, SQLite, and other SQL database support.

## Technical Context

**Language/Version**: Python 3.11+  
**Primary Dependencies**: FastMCP 2.x, asyncpg, SQLGlot, anthropic-sdk-python, openai, Pydantic  
**Storage**: PostgreSQL (external, configured via connection strings)  
**Testing**: pytest, pytest-asyncio  
**Target Platform**: Linux/macOS server, runs as MCP server via stdin/stdout  
**Project Type**: Single CLI/library project  
**Performance Goals**: <5s for typical queries (SC-001), 95% translation accuracy (SC-003)  
**Constraints**: Read-only queries, 1000 row default limit, no result data in logs  
**Scale/Scope**: Multiple databases, concurrent agent requests

```python
    ...
```

### SQL Validation (SQLGlot) - CRITICAL SECURITY GATE

**IMPORTANT**: ALL SQL must pass through validation before execution, including AI-generated SQL.

```python
import sqlglot

def validate_sql(sql: str) -> tuple[bool, str | None]:
    """
    Validate SQL is syntactically correct and read-only.
    
    CRITICAL: This MUST be called on ALL SQL before execution,
    including AI-generated SQL. Never trust AI output directly.
    """
    try:
        parsed = sqlglot.parse_one(sql, dialect="postgres")
        if not isinstance(parsed, sqlglot.exp.Select):
            return False, "Only SELECT queries are allowed. Write operations (INSERT, UPDATE, DELETE) are prohibited."
        return True, None
    except sqlglot.errors.ParseError as e:
        return False, str(e)
```

**Validation Flow**:
1. User input (NL or SQL) → AI Translation (if NL) → **validate_sql()** → Execute
2. Never bypass validation, even for "trusted" AI-generated SQL
